# Directory Directory Logo Variants

| Color | Transparent Logo | Rounded Icon | Outer D |
| --- | --- | --- | --- |
| Blue (Original) | [logo-blue.svg](logo-blue.svg) | [app-icon-blue.svg](app-icon-blue.svg) | `#0874F9` |
| Black | [logo-black.svg](logo-black.svg) | [app-icon-black.svg](app-icon-black.svg) | `#000000` |
| White | [logo-white.svg](logo-white.svg) | [app-icon-white.svg](app-icon-white.svg) | `#FFFFFF` |

The blue logo is an exact copy of the original `public/directory-directory-logo.svg` and V15 artwork. The blue rounded icon preserves the original `app/icon.svg`.

Black and white variants change only the outer D stroke and descriptive metadata. All paths, stroke widths, spacing, green/blue/red rows, and the rounded icon's light-blue tile and padding are preserved. The logo canvases are transparent; use the white-D logo on a dark background.

The shared web/native brand mark uses black in light mode and the original blue in dark mode. The browser tab follows the selected site theme: `app-icon-black.svg` for light mode and [app-icon-blue-dark.svg](app-icon-blue-dark.svg) for dark mode. The dark icon pairs the blue D with the app's `#0b1220` background. The white-D dark icon remains available as [app-icon-dark.svg](app-icon-dark.svg).

Active native icon PNGs live in `assets/icons/app-icon-black.png` and `assets/icons/app-icon-blue-dark.png`. iOS selects its light or dark icon from the system appearance; Android and the default static favicon use the black-D version. The white variants, blue SVGs, original logo path, original native icon PNG, and original `assets/icons/favicon-rounded.png` remain available.

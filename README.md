# Directory Directory

One-page landing preview built with Next.js, TypeScript, and Sass. The responsive layout follows [the V7 mockup](assets/concepts/mockups/v7/01-tabbed-folder-hero.png), with a dark theme based on [Night Search](assets/concepts/mockups/v1/02-night-search.png). A web manifest makes the page available for mobile home-screen installation when served over HTTPS.

Run `npm install` once, then `npm run dev` and open the address Next.js prints. The page includes working search, category filters, topic tabs, view controls, theme switching, and small preview dialogs for Sign in and Submit a directory.

The entries in `src/data/directories.ts` and the public-directory total are sample placeholders. Replace them with live data when the catalog is ready. The copyright year is rendered from the current year on each request.

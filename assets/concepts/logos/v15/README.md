# Directory Directory logo — V15

A refinement of the V14 favorite with shorter pills, closer rows and a yellow middle-row option.

## Artwork

- [01-indexed-d-compact-blue.svg](01-indexed-d-compact-blue.svg): compact geometry with the existing green, blue and red palette.
- [02-indexed-d-compact-yellow.svg](02-indexed-d-compact-yellow.svg): the same geometry with a yellow middle row so the three interior colors differ from the blue D.
- [03-comparison.png](03-comparison.png): side-by-side preview; [editable comparison](03-comparison.svg).

Each logo also has a 640 × 640 white-background PNG preview. The individual SVG canvases remain transparent.

## Geometry and palette

The outer D retains the exact V14 path and 9-unit blue stroke. The three pill bodies retain their 10-unit height, 5-unit end caps, seamless 6-unit tabs and left boundary at x = 29.

The pills end at x = 112, 122 and 108, each 12 units shorter than V14. Their centers are y = 66, 90 and 114; center spacing is 24 units instead of 28. This opens up the right side and draws the rows closer together.

- Outer D and blue option: `#0874F9`
- Green: `#21A668`
- Yellow option: `#F2C532`
- Red: `#D83B42`

This round uses direct SVG edits to preserve the established vector geometry. Earlier rounds remain available. No application code was changed.

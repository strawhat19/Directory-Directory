# Directory Directory — V11 logo concepts

V11 refines the [V10 indexed D](../v10/01-indexed-d-tabs.svg). The tabs are now circular lobes joined directly to the left end of each line. Their rounded curves echo the outside of the D, and the rows keep the original green, blue, and red order. Both SVGs have transparent surrounding canvases and individually named paths for editing.

| File | Treatment | Palette | Suggested use |
| --- | --- | --- | --- |
| `01-indexed-d-left-tabs-outline.svg` | Blue D and all three tabbed rows drawn as outlines. | Blue `#0874F9`, green `#21A668`, red `#D83B42` | Light, spacious app icon or navigation mark. |
| `02-indexed-d-left-tabs-fill.svg` | Solid blue D and solid tabbed rows, separated by narrow white edges. | Blue `#0874F9`, green `#21A668`, red `#D83B42`, white `#FFFFFF` | Bolder icon or small avatar. |

Earlier concept folders remain unchanged.

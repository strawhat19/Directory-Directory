# Directory Directory — V6 tricolor logo

The [V4 nested index concept](../v4/03-nested-index-hybrid.png) is the base for this mark. Its three D shapes retain the progressively smaller folder tabs. Thinner, separate outlines make blue, red, and green visible in the same symbol.

| Color | Value | Placement |
| --- | --- | --- |
| Blue | `#0874F9` | Outer D |
| Red | `#D83B42` | Middle D |
| Green | `#21A668` | Inner D |

The [transparent vector](mark-tricolor.svg) and [1024px PNG](mark-tricolor.png) are suited to layouts. The [dark launcher vector](launcher-tricolor-on-black.svg) and [1024px PNG](launcher-tricolor-on-black.png) place the same mark on `#0B1018` with clear padding.

V6 is a concept set. The app still uses the V5 icon until a logo direction is chosen.

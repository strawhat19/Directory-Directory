# Directory Directory — V7 centered tricolor logo

V7 refines the [V4 nested index concept](../v4/03-nested-index-hybrid.png) and [V6 tricolor mark](../v6/mark-tricolor.svg). All three outlines use one D path. Each copy is scaled around the same center, `(64, 64)`, with an equal step of `0.264` between scales. Their strokes are all 6 units wide, so the visible spacing stays even.

| D | Color | Scale | Horizontal centerline inset |
| --- | --- | ---: | ---: |
| Outer | Blue `#0874F9` | `0.820` | 0 |
| Middle | Green `#21A668` | `0.556` | 13.992 units |
| Inner | Red `#D83B42` | `0.292` | 27.984 units |

The [transparent SVG](mark-tricolor.svg) and [1024px PNG](mark-tricolor.png) are suited to layouts. The [dark launcher SVG](launcher-tricolor-on-black.svg) and [1024px PNG](launcher-tricolor-on-black.png) use the same geometry on `#0B1018`.

V7 is a concept set. The app icon remains V5 while these logo options are compared.

# Directory Directory — Logo Concepts V1

The Directory of Directories

Three PNG concept boards, each showing the name, tagline, primary symbol, monochrome treatment, reversed treatment, and a small icon study.

| Concept | Idea | Character |
| --- | --- | --- |
| [01 · Nested DD](01-nested-dd.png) | A directory inside a directory, expressed through nested D letterforms | Bold, compact, direct |
| [02 · Tabbed Index](02-tabbed-index.png) | A layered collection of directories | Familiar, organized, approachable |
| [03 · Discovery Asterisk](03-discovery-asterisk.png) | Four directory tabs meeting at one central index | Editorial, colorful, curated |

**Recommended starting point: Nested DD.** It connects the repeated name to a compact symbol and has the simplest silhouette for a future app icon.

These are raster concept studies, not final vector logo or favicon exports. Generated using the built-in image generation tool. The complete generation and refinement prompts are in [PROMPTS.md](PROMPTS.md).

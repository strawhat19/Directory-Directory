# Directory Directory — V8 balanced tricolor logo

V8 uses the [V7 mark](../v7/mark-tricolor.svg) as its base. The D geometry, colors, horizontal centers, and 6-unit strokes stay the same. The green and red Ds move down so each raised inner tab has the same clear vertical space above it as the bottom of that D has below it.

| Pair | Gap above inner tab | Gap below inner D |
| --- | ---: | ---: |
| Blue / green | 7.988 units | 7.988 units |
| Green / red | 9.836 units | 9.836 units |

The measurements compare the parent D's upper horizontal edge after its index tab with the inner D's top tab, then compare their bottom edges. Shared path geometry keeps the D shapes consistent.

Use the [transparent SVG](mark-tricolor.svg) or [1024px PNG](mark-tricolor.png) in layouts. The [dark launcher SVG](launcher-tricolor-on-black.svg) and [1024px PNG](launcher-tricolor-on-black.png) put the same mark on `#0B1018`.

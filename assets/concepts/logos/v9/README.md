# Directory Directory — V9 logo concepts

V9 explores the directory metaphor beyond the balanced nested D in [V8](../v8/README.md). These are concept assets; the app icon is unchanged. Each SVG is editable and includes a title, description, and named shapes.

| Concept | Direction | Suggested use |
| --- | --- | --- |
| [01-indexed-d.svg](01-indexed-d.svg) | A tabbed D with three colored listing rows. | Simple navigation mark or favicon. |
| [02-catalog-stack.svg](02-catalog-stack.svg) | Staggered index folders with a white D on a dark tile. | App launcher or social avatar. |
| [03-discovery-lens.svg](03-discovery-lens.svg) | A search lens inside the brand's tabbed D. | Search entry point or product illustration. |

The palette follows the established set: blue `#0874F9`, green `#21A668`, red `#D83B42`, and dark navy `#0B1018`. Concepts 01 and 03 have transparent backgrounds; concept 02 includes its own dark tile. Keep each mark's viewBox proportions intact when scaling.

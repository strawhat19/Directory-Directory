# Directory Directory logo concepts — V13

The original [V9 indexed D](../v9/01-indexed-d.svg) supplies the outline and exact palette. The folder rows develop [V12's outline concept](../v12/01-indexed-d-folder-tabs-outline.svg).

## Indexed D refinements

- `01-indexed-d-seamless-tabs.svg` — original D with enlarged outlined folder rows.
- `02-indexed-d-filled-rows.svg` — same geometry with solid rows, closer to V9's bold interior marks.

The enclosing D path and 9-unit stroke are copied directly from V9. Row bodies grow from 10 to 14 units high and move to centers y = 62, 90 and 118. Their full horizontal extents are x = 29–124, 29–134 and 29–120, using the space inside the curved D with balanced breathing room.

Every row is one closed path. Its left boundary rises continuously from the lower capsule curve into the rounded top-left tab, with no inset step or overlapping tab seam. The tab transitions through a softened shoulder into the pill's upper edge.

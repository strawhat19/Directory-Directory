## 01-clear-index

Use case: ui-mockup. Create a high-fidelity desktop landing page HERO mockup for an eventual web app called "Directory Directory", described as "The Directory of Directories". Show only the first viewport at approximately 1536×1024, from top navigation through the hero and the first hint of browsing UI; no browser chrome, no footer, no long sections, no lorem ipsum. This should look like a polished, buildable web interface rather than a poster. Use the attached image ONLY as the exact brand reference: the approved V4 nested tabbed D symbol. The navigation header MUST show that same distinctive D symbol with tabs on every nested level, small but legible, next to the exact text "Directory Directory". Do not reproduce the reference image's white presentation board or its lower icon studies. Keep header logo proportions faithful. Build the interface around finding curated directories: prominent search input, clear browse options, meaningful but minimal labels. Pixel-precise grid, spacing, realistic controls, readable typography and sensible UI hierarchy. Crisp flat digital UI, no 3D, no photographs, no fake statistics, no testimonials, no watermarks, no arbitrary garbled copy. Use these exact spelled words where specified; omit extra text if uncertain.
Direction: CLEAR INDEX. Palette: warm off-white (#F7F5EF), ink navy (#0D1B35), cobalt blue (#075CEB) for the approved nested tabbed D mark and calls to action. Spacious two-column hero. Top nav: logo left; links "Explore", "Topics", "About" center/right; a subtle outlined "Submit a directory" button. Left hero copy: small eyebrow "THE DIRECTORY OF DIRECTORIES"; large headline exactly "Find the right directory."; short supporting line exactly "Explore curated directories for the things you're looking for." Beneath, very prominent search input with placeholder "Search directories or topics..." and a cobalt "Search" button. Then a row of restrained chips "Design", "Software", "Local", "Learning". Right hero visual: three elegant overlapping flat folder/index cards, their staggered little tabs echoing the selected brand symbol. Each card has a single large category label, for example "Create", "Learn", "Explore". No tiny faux listings. Editorial modern sans typography; airy but concrete, sophisticated and useful. No content extends below the fold.

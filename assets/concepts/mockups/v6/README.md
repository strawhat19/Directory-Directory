# Directory Directory — Landing Hero Mockup V6

[View the V6 mockup](01-folder-hover-hero.png)

This iteration of the [V5 hero](../v5/01-tabbed-landing-hero.png) refines the tab and folder details using the selected [V4 logo](../../logos/v4/03-nested-index-hybrid.png).

- The six topic tabs remain one connected group, with a visible gap before separate Grid, Table, and List view controls.
- The full light-blue nested D sits in open hero space above the cards. Its innermost visible D also has a tab.
- Each hero category card has a tab connected to a top folder seam.
- The Tools card shows a static open/hover state with a mouse pointer; the other three are closed.

This is a 1536×1024 PNG concept made with the built-in image generation tool. The generation and targeted refinement prompts are in [PROMPTS.md](PROMPTS.md).

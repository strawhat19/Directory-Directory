# Directory Directory — Landing Hero Mockup V5

[View the V5 mockup](01-tabbed-landing-hero.png)

This refines the [V4 left-aligned mockup](../v4/01-refined-left.png) using the selected [V4 nested-index logo](../../logos/v4/03-nested-index-hybrid.png) as the tab-shape reference.

- The main heading fits on one line.
- Sign in and Search use cobalt buttons with integrated top-left tabs.
- Explore directories is a raised tab attached to the section border.
- Featured, Popular, Latest, Trending, Staff Picks, and All form a continuous divider-tab rail from the left.
- Grid and list view controls finish the rail with their own tabs.
- Category-card tabs use the same short flat top and softened shoulder motif.

This is a 1536×1024 PNG visual concept made with the built-in image generation tool. The full edit prompt is in [PROMPT.md](PROMPT.md).
